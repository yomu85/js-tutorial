## 🚀 시작하기

```bash
# 프로젝트 생성
npm create vite@latest js-tutorial -- --template vanilla

# 의존성 설치
cd js-tutorial
npm install

# 개발 서버 실행
npm run dev
```

서버 실행 후 `http://localhost:5173` 에서 확인할 수 있습니다.
