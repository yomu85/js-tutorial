# 렉시컬 환경 개념
## 호이스팅 = 선언을 렉시컬 환경에 미리 등록
var: 등록 + undefined 초기화
let/const: 등록만 (<uninitialized>)
function: 등록 + 함수 전체 초기화

## 함수 관련 정의
함수 선언문:
✅ 등록 + 함수 전체 초기화
✅ 선언 전에 호출 가능

함수 표현식:
✅ 변수 규칙 따름 (let/const/var)
❌ 선언 전에 호출 불가

### 상기 예시
``` javascript
// 함수 선언문
console.log(typeof func1);  // "function" ✅
function func1() {}

// 함수 표현식 (const)
console.log(typeof func2);  // ❌ ReferenceError
const func2 = function() {};

// 함수 표현식 (var)
console.log(typeof func3);  // "undefined" ✅
var func3 = function() {};
```

## 렉시컬 환경 생성 = 전체 구조 생성

``` javascript
function test() {
  let x = 10;
}

test();  // ← 이 순간!
```

## 생성되는 것
┌─────────────────────────────────┐
│ 렉시컬 환경 생성 ✅              │
├─────────────────────────────────┤
│ ┌─────────────────────────────┐ │
│ │ 환경 레코드 생성 ✅          │ │
│ │ ├─ x: 10 ✅                 │ │
│ │ └─ this ✅                  │ │
│ └─────────────────────────────┘ │
│                                 │
│ 외부 렉시컬 환경 참조 생성 ✅   │
│ → 전역을 가리킴                 │
└─────────────────────────────────┘

## 한 번에 생성
test() 호출
  ↓
렉시컬 환경 생성 (컨테이너)
  ├─ 환경 레코드 생성 (저장소)
  │  └─ 변수들 초기화
  └─ 외부 참조 설정 (링크)

## 시간 순서
1. 함수 호출
   ↓
2. 렉시컬 환경 객체 생성
   ↓
3. 환경 레코드 생성 (내부)
   ↓
4. 변수 초기화
   ↓
5. 외부 참조 설정
   ↓
6. 함수 코드 실행

### 렉시컬 환경 생성 = 상하위 구조 전체가 한 번에 생성!
