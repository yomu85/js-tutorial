# 웹브라우저의 단기/임시 저장소
## 단기 메모리 (휘발성)

- 메모리 캐시: 현재 페이지의 리소스를 RAM에 임시 저장, 탭 닫으면 사라짐
- 세션 스토리지: 탭/윈도우 단위로 데이터 저장, 탭 닫으면 삭제 (약 5-10MB)

## 중장기 저장소 (영구적)

- 로컬 스토리지: 명시적으로 삭제하기 전까지 영구 보관 (약 5-10MB)
- 쿠키: 만료 시간 설정 가능, 서버로 자동 전송 (4KB 제한)
- 디스크 캐시: HTTP 캐시 헤더 기반으로 파일 저장, 브라우저가 관리

  브라우저 캐시 (넓은 의미)
  ├─ 메모리 캐시 (Memory Cache) ← RAM에 저장
  │  └─ 수명: 탭 닫기 전까지
  │
  └─ 디스크 캐시 (Disk Cache) ← 하드드라이브에 저장
    └─ 수명: 캐시 정책에 따라 (며칠~몇 달)

## 추가 저장소 (덜 일반적)

- IndexedDB: 대용량 구조화된 데이터 저장 (수백MB~GB)
- Cache API: Service Worker용 리소스 캐시
- Web SQL (deprecated)

## 메모리 캐시 수명 정리:

✅ 캐시가 유지되는 경우:
- 같은 페이지 내에서 작업할 때 (새로고침 전까지)
- SPA 내 라우팅 (페이지 재로드 없이 이동)

❌ 캐시가 사라지는 경우:
- 페이지 새로고침 (F5) - JavaScript 재실행
- 강력 새로고침 (Ctrl+F5) - JavaScript 재실행
- 다른 페이지로 이동 - 새로운 환경
- 뒤로가기/앞으로가기 - 페이지 재로드됨
- 탭 닫기 - 탭 종료
- 브라우저 닫기 - 모든 탭 종료


## 프론트엔드 개발자 디스크 캐시 제어 간접 제어만 가능

``` javascript
// 방법 1: URL 변경 (가장 확실)
<script src="app.js?v=2"></script>
<script src="app.abc123.js"></script>

// 방법 2: fetch 옵션 (서버 협조 필요)
fetch('api/data', {
  cache: 'no-cache',    // 재검증 요청
  cache: 'reload',      // 캐시 무시
  cache: 'force-cache'  // 캐시 강제 사용
});

// 방법 3: Service Worker (고급)
self.addEventListener('fetch', (event) => {
  // 캐시 전략 직접 구현
  event.respondWith(
    caches.match(event.request)
      .then(response => response || fetch(event.request))
  );
});
```


# 데코레이터(Decorator)란?
## 정의: 원본 함수를 수정하지 않고, 그 함수를 감싸서(wrap) 새로운 기능을 추가하는 함수

┌─────────────────────────────────────┐
│      데코레이터 함수                │
│  function cachingDecorator(func)    │
│                                     │
│  ┌───────────────────────────────┐ │
│  │     래퍼 함수                 │ │
│  │  return function(x) {         │ │
│  │    // 추가 기능 (캐싱)        │ │
│  │    func(x);  // 원본 호출     │ │
│  │  }                            │ │
│  └───────────────────────────────┘ │
└─────────────────────────────────────┘


원본 함수 = 선물 상자
데코레이터 = 포장지

┌─────────────────────┐
│   포장지 (로깅)      │  ← 데코레이터 3
│  ┌───────────────┐  │
│  │ 포장지 (타이밍)│  │  ← 데코레이터 2
│  │ ┌──────────┐ │  │
│  │ │ 포장지   │ │  │  ← 데코레이터 1
│  │ │ (캐싱)   │ │  │
│  │ │ ┌──────┐ │ │  │
│  │ │ │ 선물 │ │ │  │  ← 원본 함수
│  │ │ └──────┘ │ │  │
│  │ └──────────┘ │  │
│  └───────────────┘  │
└─────────────────────┘

선물(원본)은 그대로, 포장만 추가!
